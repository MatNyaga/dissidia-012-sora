## In plain words (for Mat)
- Every time we build a new test disc, a helper has been running about a dozen check tools by hand and copying the
  results into a note. Now **one command** does all of the "no emulator" checks on a disc and writes a report that
  says PASS or FAIL, with the reason and the log file of every tool:
  `python3 -I tools/qa/acceptance/run_static.py --disc DISC --profile p24-items`.
- What the disc is *supposed* to be is written in a small **profile** file (which fighter numbers, which differences
  from the reference disc are allowed, which module file it must carry …). Sora's discs have profiles now; fighter #2
  gets its own profile, the tool stays the same.
- I proved it on real discs (reading only): the reference disc against itself passes, the P2.4 disc you tested on
  the Vita passes, the old disc that froze the emulator **fails for exactly the reason we found last week** (the
  module calling game code with a crooked stack — the kit now spots that without starting the game), and a copy
  that I broke on purpose (Sora's name removed from the Opponent Info screen) fails with that reason on four
  different checks. The broken copy is deleted.
- For the emulator checks there is a second command, `runtime_plan.py`, that prints the exact step-by-step list and
  commands for a helper to run later (it runs nothing itself).
- For you there is a **five-minute Vita checklist** (§5) in plain words.
- I also went through the acceptance list against what we learned in P2.3 / P2.4 and wrote a corrected list (§4):
  about a dozen new items (for example "the module keeps the stack straight", "the game still works with the module or the
  registry missing", "menu speed in the Shop list, not only on still screens", "check the battle-setup screenshot
  before every test battle"), and the outdated lines marked.

## 5. Vita checklist (C items) — five minutes, for Mat
Before you start: Claude copies the disc to the card, checks it after a remount and ejects it. Keep your old Dissidia
save backed up (it is already on your PC). In Adrenaline: game plugins **off**, CPU clock **Default**.

1. **Start the game** (Adrenaline → Memory Stick → the disc Claude named). It reaches the title screen and loads your
   save. *Fail = black screen or freeze → stop here and tell Claude.*
2. **Character select** (Quick Battle): the new fighter is on the bottom row with his own face and his own text.
3. **One battle**: the new fighter against any CPU (CPU strength Minimal, stage Order's Sanctuary is fine). Use a
   few attacks for about a minute. You see his own moves and hear his own voice, not Cloud's.
4. In the same battle: fill the EX gauge, press **R + □** (EX Mode), then do his **full EX Burst** (hit with an HP
   attack in EX Mode, then mash ○ as fast as you can). It plays to the end and the battle goes on. *A freeze here is
   important — tell Claude.*
5. **Finish the battle** (win or forfeit) and go back to the menu. No freeze, the result screen looks normal.
6. **Shop → Buy**: open the item list and scroll a bit. It should feel as fast as on the original game.

Write one line per step: OK / not OK (a phone photo of anything odd helps). That's it.
If you have more time (only when Claude asks for it): Original Quest slot with the fighter (V6), Data Install and a
battle again (V7, only on release discs), the fighter as an assist (V8, only if he has one).
